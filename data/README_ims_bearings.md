## What the readme inside the archive states (read 2026-10-31)

```text
rig        4 Rexnord ZA-2115 double-row bearings on one shaft, 2000 RPM, radial load 6000 lb,
           force lubricated; PCB 353B33 accelerometers on the bearing housings
snapshots  1-second vibration snapshots, 20,480 points at 20 kHz, ASCII, file name = timestamp
set 1      2003-10-22 12:06:24 .. 2003-11-25 23:39:56, 2,156 files, 8 channels (2 per bearing),
           every 10 min (first 43 files every 5 min). End of test: inner race defect in
           bearing 3, roller element defect in bearing 4
set 2      2004-02-12 10:32:39 .. 2004-02-19 06:22:39, 984 files, 4 channels, every 10 min.
           End of test: outer race failure in bearing 1
set 3      2004-03-04 09:27:46 .. 2004-04-04 19:01:57, 4,448 files, 4 channels, every 10 min.
           End of test: outer race failure in bearing 3
all        "All failures occurred after exceeding designed life time of the bearing which is
           more than 100 million revolutions."
```

## Mismatch kept as delivered

Set 3 is delivered as `3rd_test.rar`, which unpacks to the folder `4th_test/txt/` and holds
**6,324** snapshots running to 2004-04-18 02:42:55. The readme states 4,448 files ending
2004-04-04 19:01:57; exactly 4,448 delivered files fall inside that window. The analysis
uses those 4,448 (pre-registered in `scripts/real_data_titration.py`). The 1,876 later
snapshots are not analysed; what they are is unresolved.
