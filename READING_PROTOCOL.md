# Reading protocol

## How to read this repo
- MAP, NOT PRESCRIPTION. Nothing here says "do it this way." It marks a sensed shape for checking.
- ERRORS ARE DATA. Where it doesn't line up with what you find, that mismatch is the map. Record it in the claim table. No shame attaches to being wrong.
- CHECK IT. Double, triple, quadruple. Accuracy comes from checking, not from who wrote it. Authorship is intentionally anonymous.
- DESIGN LIFE. This comes from an engineering practice that builds for the lifespan of the need, not for permanence. A structure for one season is built to return to and feed the environment for the next use. Read the repos the same way: built for what's needed now, revisable, not monuments.
